# Caskaydia Nerd Mono

CaskaydiaMono Nerd Font Regular, converted to WOFF2 without subsetting so the
Nerd Font symbols remain available. Based on Microsoft Cascadia Mono and the
[Nerd Fonts](https://github.com/ryanoasis/nerd-fonts) distribution.

The SIL Open Font License is in `OFL.txt` and is embedded alongside the font in
the generated dashboard HTML. No font tooling is needed to build the project.
